The problem

Every wallet today is owned by a key
a quantum computer could recover

  • → Shor's algorithm breaks the discrete-log assumption behind ECDSA.
  • → A public address is enough input to derive the private key.
  • → QMS plans PQ accounts for v1. This is a working preview, today.
